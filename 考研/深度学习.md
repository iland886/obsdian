## 泛化与正则化
- 欠拟合and过拟合
	- 欠拟合：在训练集上错误率很低，但在验证集上错误率也很低。   模型太简单
	- 过拟合：在训练集上错误率很低，但在验证集上错误率很高。
	  往往是由训练数据少或者噪声造成的
- 泛化误差 = 期望风险 - 经验风险
  我们希望期望风险低，泛化误差也低
  - 如何减少泛化误差
    1. 优化
    2. 正则化

## 模型选择与偏差方差分解
- 模型选择
	- 按过拟合和欠拟合分类模型的能力
	- 如何选择？
		- 引入验证集   在训练集上训练不同的模型，选择在验证集上错误率最小的模型
	- 交叉验证   k折交叉验证    将训练集分成K组，每次使用k - 1组作为训练集，剩下一组作为验证集，选择验证集上平均性能最好的一组。
- 模型选择的准则
	- 在模型复杂度和期望风险之间做平衡
	- 期望风险   ![[Pasted image 20250909205859.png]] 后面的一项是无法避免的，通常是由样本的噪声造成的
	- 期望错误可以分解为![[Pasted image 20250909210234.png]]
- 偏差与方差
	偏差：模型预测值和真实值之间的差距
	高偏差表示模型过于简单，拟合能力不行，容易出现欠拟合
	
	方差：模型在不同训练集上出现的波动大小
	高方差表示模型过于复杂，比如高次多项式回归，数据集一旦有稍微的变化就会导致预测结果不稳定，容易过拟合
	![[Pasted image 20250909210430.png]]最小期望风险等价于最小化偏差和方差之和。
	
	集成模型能有效降低方差。

## 交叉熵和对数似然
 - 熵 
	 - 在信息论中，熵用来衡量一个随机事件的不确定性
		 - 熵越高，表示随机变量信息越多，不确定性越大
		 - 熵越低，表示随机变量信息越少，不确定性越小
	 - 自信息
		 - 一个随机事件包含的信息量
		 - 对一个随机变量X = x时的自信息为$$I(x) = -logp(x)$$
	 - 熵就是随机变量X的自信息的数学期望$$H(x) = E_X[I(x)] = -\sum_{x\in X}p(x)logp(x)$$
	 - 熵编码
		 - 概率越高，码字越短，概率越低，码字越长
 - 交叉熵
	 - 按照概率分布q的最优编码对真实分布为p的信息进行编码的长度![[Pasted image 20250910195835.png]]
 - kl散度
	 - 用概率分布q来近似真实分布p时造成的信息损失量$$KL(p,q) = H(p,q) - H(p) = \sum_xp(x)logp\frac{p(x)}{q(x)}$$
	 - p,q差距越大，kl散度越大
 - 应用到机器学习
	 - 分类情况![[Pasted image 20250910200631.png]]最小化kl散度也就是最小化交叉熵，最大化似然

## logistic回归
- logistic函数$$\sigma(x) = \frac{1}{1 + exp(-x)}$$
	- 和sigmoid函数一样称为s型函数，两段饱和，中间部分近似线性
- logistic回归 
	- 与分类学习不一样，将输出映射到0-1的概率区间上
- 学习准则
	- 预测条件概率$$p_\theta(y = 1|x) = \sigma(-w^Tx)$$
	- 真实条件概率$$\begin{align*}p_r(y=1|x) &= y^*\\p_r(y=0|x)&=1-y^* \end{align*} $$
	- 衡量两个分布的差异![[Pasted image 20250910203500.png]]
	- 梯度下降求解![[ff0ccd44a190373bc6e0cae5d9f3e76e.png|400]]

## 卷积
- 定义：在信号处理中，用于计算信号的延迟累积
	- 给定一个输入信号序列x和滤波器w，卷积的输出为：$$y_t = \sum_{k=1}^{K}w_kx_{t-k+1}$$
	- 输入长度N，滤波器长度K，输出长度为N-K+1
- 作用：
	- 近似微分
	- 低通、高通滤波
	- 作为特征提取器
- 卷积扩展
	- 引入滑动步长S和填充P
	- S：减少输出长度
	- P：增加输出长度
- 卷积类型
	- 窄卷积
	- 宽卷积
	- 等宽卷积
	- 二维卷积

## 神经网络优化的特点
- 网络优化的特点
	- 结构差异大
		- 没有通用的优化算法 
		- 超参数多
	- 非凸优化问题
		- 参数如何初始化
		- 逃离局部最优或鞍点
		- 梯度消失or爆炸 
	- 高维空间的非凸优化问题
		- 逃离鞍点
		- 平坦最小值
	- 优化地形的可视化
		- 在高维空间中损失函数的曲面形状

- 改善方法
	- 更有效的优化算法提高优化方法的效率和稳定性
	- 参数初始化，数据预处理
	- 修改网络结构
	- 更好的超参数优化方法

## 优化算法的改进
- 随机梯度下降
	- 改进：小批量随机梯度下降MiniBatch
	- 随机选择K个训练样本，梯度的计算，学习率
- 批量大小
	- 批量大小不影响随机梯度的期望，但会影响随机梯度的方差（在不同数据集上的学习效果不一样）
	- 批量大小和学习率（步长）的关系：
	  线性缩放规则 ：当批量大小增加m倍，学习率也增加m倍，当批量大小非常大时，线性缩放会使得训练不稳定。
	- 批量大小对收敛的影响 
		- 批量越小，随机性越大，泛化能力更好$$epoch = (\frac{训练样本的数量N}{批次大小K}）X 迭代$$

## 动态学习率
既不能太低也不能太高
学习率过大可能导致模型无法收敛，过小收敛速度会变慢
- 学习率衰减
	- ![[Pasted image 20250916162537.png]]
	- 周期性学习率衰减
	- 其他学习率调整方法
		- 增大批量大小变相的减小学习率
		- 学习率预热
- 自适应学习率
	- adagrad算法：每次迭代时自适应地调整每个参数的学习率
		  1. 在第t次迭代时先计算每个参数梯度平方的累计值
		  2. 参数更新差值，𝜖 是为了保持数值稳定性而设置的非常小的常数
		- 优点：若某个参数的偏导数比较大，其学习率相对较小
		- 缺点：在迭代一定次数后如果没有找到最优点，此时学习率比较小，很难继续找到最优点。
	- RMSprop算法：自适应学习率方法，在有些情况可以避免AdaGrad算法中**学习率不断单调下降以至早衰**的缺点
			1. 计算每次迭代梯度$g_t$平方的指数衰减移动平均![[Pasted image 20250917194959.png]]
			   $\beta$ 是衰减程度
			2. 参数更新差值
	- AdaDelta算法：和RMSprop算法类似，也是计算梯度平方的指数衰减移动平均来调整学习率，额外还引入了每次参数更新差值Δ𝜃 的平方的指数衰减权移动平均。![[Pasted image 20250917195735.png]]
		- 在一定程度上平抑了学习率的波动
	- ![[Pasted image 20250916163129.png]]

## 梯度方向优化

- 动量法
	- 用之前累积的动量代替真正的梯度 在第 𝑡 次迭代时，计算负梯度的“加权移动平均”作为参数的更新方向，![[Pasted image 20250916202048.png]]
-  NAG ：一种对动量法的改进
	  在动量法中实际的参数更新方向为上以更新方向Δ𝜃𝑡−1 和当前梯度的反方向 −𝒈𝑡 的叠加![[Pasted image 20250917205131.png]]
	  比动量法好处是预测下一步的位置调整方向进行更新参数，
- 梯度方向优化+自适应学习率
	- adam算法=动量法+ RMSprop![[Pasted image 20250916202947.png]]
	- 自适应学习率、收敛快、在稀疏梯度问题特别有效
	- 为什么要修正：如果不修正，初期的有效学习率会变得非常小，更新过慢。

## 暂退法dropout
- 训练一个神经网络时，丢弃一部分神经元来避免过拟合。由于每次选择丢弃的神经元都是随机的，可以设定一个固定的概率p，对每个神经元都以概率p来判断要不要保留，对一个神经层，引入一个maxk掩蔽函数来判断是否丢弃![[Pasted image 20250917171753.png]]
- dropout意义

	- 贝叶斯学习角度理解：![[Pasted image 20250917172821.png]]
- 在循环神经网络上的丢弃法
	- 不能直接对每个时刻的隐状态进行随机丢弃，因为会损害到循环网络在时间维度上的记忆能力(h1->h2)，应对非时间维度的连接进行丢弃![[Pasted image 20250917172624.png]]
	- 对参数矩阵的每个元素进行随机丢弃，并在所有时刻使用相同的丢弃掩码，这种方法称为变分丢弃法![[Pasted image 20250917172618.png]]

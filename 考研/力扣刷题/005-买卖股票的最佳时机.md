## 📘 题目描述
给定一个数组 `prices` ，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你只能选择 **某一天** 买入这只股票，并选择在 **未来的某一个不同的日子** 卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0` 。

---

## 🧠 解题思路

- 解法一（暴力）：第一天买入，可以在n-1天中卖出，第i天买入，可以在n - i 天卖出，时间负载度为1 + 2 + ... + n =O($n^2$)  
- 解法二（优化）：利用动态规划
	- 在第i天的最大利润要在第i天选择卖出或者不卖出股票：
	  若不卖，该天最大利润为前一天的最大利润
	  若卖，最大利润即当天的股票减去之前以最低价格购入的股票
	  递推结构：dp[i] = max(dp[i -1], prices[i] - minprices)          minprices前i天中股票最低的价格
- 核心算法思想：动态规划 / 贪心 / 哈希表 / 双指针 等

---

## 💻 代码实现（C++）

```cpp
class Solution {

public:

    int maxProfit(vector<int>& prices) {

        int n = prices.size();

        vector<int>dp(n + 1, 0);

        int minprice = prices[0]

        ;

  

        for (int i = 1; i <= n; i++)

        {

          minprice  = min(minprice, prices[i- 1]);

          dp[i] = max(dp[i -1], prices[i -1] - minprice);

        }

        return dp[n];

    }

};

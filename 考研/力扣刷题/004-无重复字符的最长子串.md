## 📘 题目描述

给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长连续子 字符串** 的长度。

---

## 🧠 解题思路

- 定义左右指针 p1 和 p2，维护一个最大区间，表示该区间内没有重复的元素，同时定义一个集合用来存储遍历的元素，以检查是否存在重复元素。

- 先移动右指针 p2，若 p2 指向的元素在集合中不存在，则将其添加到集合中，更新当前子串的长度 length，并将右指针 p2 加1，继续移动，直到右指针超出子串长度。

- 若右指针 p2 指向的元素在集合中存在，说明不满足条件，此时向右移动左指针 p1，并在移动过程中逐步移除左指针指向的元素，直到集合中不再包含右指针指向的元素。移动完成后，继续移动右指针 p2，并更新长度 length。
---

## 💻 代码实现（C++）

```cpp
class Solution {

public:

    int lengthOfLongestSubstring(string s) {

      int p1 = 0, p2 = 0;

      int len =0, max_len = 0;

      unordered_set<char>occ;

  

      while (p2 < s.size())

      {

        if (occ.find(s[p2]) == occ.end())

        {

          occ.insert(s[p2++]);

          len++;

          max_len = max(len, max_len);

        }

        else

        {

          while (occ.find(s[p2]) != occ.end())

          {

            occ.erase(s[p1++]);

            len--;

          }

          occ.insert(s[p2++]);

          len++;

        }

      }

      return max_len;

  

    }

};

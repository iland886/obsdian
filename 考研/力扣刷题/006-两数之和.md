## 🧠 解题思路

- 解法一（暴力）：两个for循环，第一次找num[i]， 第二次找target - num[i]
- 解法二（优化）：创建一个哈希表，遍历nums,如果target - nums[i] 在哈希表中，返回target - num[i]的下标和i,如果不存在,将num[i]和下标i加入。
- 核心算法思想：动态规划 / 贪心 / 哈希表 / 双指针 等

## 💻 代码实现（C++）

```cpp

  class Solution {

	public:
	
	    vector<int> twoSum(vector<int>& nums, int target) {
	
	        unordered_map<int, int>hashtable;
	
	        for (int i = 0; i < nums.size();i++)
	
	        {
	
	            auto it = hashtable.find(target - nums[i]);
	
	            if (it != hashtable.end())
	
	            {
	
	                return {it->second, i};
	
	            }
	
	            hashtable[nums[i]] = i;
	
	        }
	
	        return {};
	
	    }
	
	};
